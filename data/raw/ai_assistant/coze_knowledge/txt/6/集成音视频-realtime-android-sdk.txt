集成音视频 Realtime Android SDK
本文档介绍如何集成扣子 Realtime Android SDK，将你在扣子中搭建的 AI 智能体集成到你的 Android 应用中，实现用户与智能体进行音视频通话。
扣子 Realtime Android SDK 封装了火山引擎 Android RTC 音视频链路相关 API，接入流程简洁高效。
准备工作
开始集成 Realtime SDK 前，请确保开发环境满足以下要求：
操作\n
	
说明\n

发布智能体\n
	
已成功搭建并发布智能体为 API 服务。搭建步骤请参见\n搭建一个 AI 助手智能体，发布步骤请参见\n发布智能体为 API 服务。\n
说明
若需使用视频理解能力，请为智能体配置一个视觉模型，例如豆包视觉理解模型。 \n
\n


获取访问密钥\n
	
获取访问密钥，用于身份认证与鉴权。\n

线上环境：在线上环境中，应使用 OAuth 鉴权方案。OAuth 鉴权方案的详细说明请参见\nOAuth 授权概述。\n
说明

步骤一：（可选）创建并配置 Android 项目
本步骤为如何创建一个新项目，如集成到已有项目，请直接查看步骤二。

在 IRTCRoomEventHandler 回调中重写onUserMessageReceived方法，解析接收到的用户消息，根据消息中的 event_type 进行不同处理，调用 updateMessage() 方法将消息内容更新到界面上。

Kotlin

@Override\n
public void onUserMessageReceived(String uid, String message) {\n
    try {\n
        Map<String, Object> messageMap = mapper.readValue(message, new TypeReference<Map<String, Object>>() {});\n
        Log.d(TAG, "接收到原始消息: " + messageMap);\n
\n
        Map<String, String> jsonMap = new HashMap<>();\n
        for (Map.Entry<String, Object> entry : messageMap.entrySet()) {\n
            try {\n
                if (entry.getValue() instanceof String) {\n
                    jsonMap.put(entry.getKey(), (String) entry.getValue());\n
                    continue;\n
                }\n
                String jsonValue = mapper.writeValueAsString(entry.getValue());\n
                jsonMap.put(entry.getKey(), jsonValue);\n
            } catch (JsonProcessingException e) {\n
                Log.e(TAG, "序列化value失败: " + entry.getKey(), e);\n
            }\n
        }\n
        if (ChatEventType.CONVERSATION_MESSAGE_DELTA.getValue().equals(jsonMap.get("event_type"))){\n
            Message msg = mapper.readValue(jsonMap.get("data"), Message.class);\n
            updateMessage(msg.getContent());\n
        } else if (ChatEventType.CONVERSATION_MESSAGE_COMPLETED.getValue().equals(jsonMap.get("event_type"))) {\n
            updateMessage("\n");\n
        }\n
    } catch (JsonProcessingException e) {\n
        Log.e(TAG, "解析消息失败", e);\n
    }\n
}

停止音视频通话
1.
调用 leaveRoom()、destroy() 方法离开并销毁房间。
2.
调用 stopVoice()和stopVideo() 方法停止音视频采集。
3.
调用 destroyRTCVideo() 方法销毁引擎。
Java
Kotlin
\n
private void disconnect(){\n
    if (rtcRoom != null) {\n
        rtcRoom.leaveRoom();\n
        rtcRoom.destroy();\n
    }\n
    if (rtcVideo != null){\n
        stopVoice();\n
        stopVideo();\n
        RTCVideo.destroyRTCVideo();\n
        rtcVideo = null;\n
    }\n
    ToastUtil.showAlert(this, "断开连接成功");\n
}
