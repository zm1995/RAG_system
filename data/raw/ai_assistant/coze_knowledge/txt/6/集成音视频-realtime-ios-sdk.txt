集成音视频 Realtime iOS SDK
扣子 Realtime SDK iOS 版基于火山引擎 RTC SDK 进行封装，支持将扣子的智能体功能与火山引擎 RTC SDK 集成，实现与智能体的实时音视频通话。扣子提示 Swift 和 Objective-C 语言的示例项目源码，你可以参考示例项目源码，快速从零开始构建一个简单的音视频通话应用。

            userInfo: [NSLocalizedDescriptionKey: response.msg])\n
    }\n
    roomInfo = response.data\n
} catch {\n
    print("连接失败: \(error)")\n
}

实时字幕显示
处理接收到的用户消息并实时显示字幕。
Swift
Objective-C
当收到 conversation.message.delta 事件时，系统会根据事件类型处理消息：\n
如果是新消息，则通过messageList.append(message)将其添加到消息列表中。\n
如果是消息的增量更新，则通过lastMessage += message对最后一条消息进行追加更新。\n
处理完成后，调用messageTableView.reloadData()方法，刷新 UITableView 并显示最新的字幕内容。\n
\n
func addMessage(_ message: String, eventType: String) {\n
    DispatchQueue.main.async {\n
        if self.lastEventType == "conversation.message.delta" {\n
            if var lastMessage = self.messageList.last {\n
                lastMessage += message\n
                self.messageList[self.messageList.count - 1] = lastMessage\n
            }\n
        } else if eventType == "conversation.message.delta" {\n
            self.messageList.append(message)\n
        }\n
        \n
        self.lastEventType = eventType\n
        self.messageTableView.reloadData()\n
    }\n
}\n

打断通话
调用 sendUserMessage 方法，实现在语音通话过程中，用户可以打断通话。打断通话后，将停止音频流输出。
Swift
Objective-C
\n
\n
@objc private func interruptButtonTapped() {\n
    let message = [\n
        "id": "event_1",\n
        "event_type": "conversation.chat.cancel",\n
        "data": "{}"\n
    ]\n
    \n
    do {\n
        let jsonData = try JSONSerialization.data(withJSONObject: message)\n
        if let jsonString = String(data: jsonData, encoding: .utf8) {\n
            self.rtcRoom?.sendUserMessage(\n
                APIConfig.botId, \n
                message: jsonString,\n
                config: ByteRTCMessageConfig.reliableOrdered)\n
        }\n
    } catch {\n
        print("Error creating JSON: \(error)")\n
    }\n
}

常见问题
编译时提示 Sandbox: rsync.samba(xxxxx) deny(1)
Xcode 15 及以上版本如果提示该错误，请按以下步骤进行处理：
在 Xcode 中，选中项目，选择 TARGETS > 项目名称 > Build Settings，在 Build Options 区域，将 User Script Sandboxing 的值修改为 No。
编译时提示 No such module 'VolcEngineRTC'
请使用 iOS 真机进行测试，不支持使用模拟器运行。
提示 doesn't match RTCDemo-Swift.app's iOS  deployment target
该错误可能是由于真机的 iOS 版本与 Xcode 的配置版本不一致导致的。解决方法如下：
在 Xcode 中，选中项目，选择 TARGETS > 项目名称 > General。在 Minimum Deployments 区域，将 iOS 版本号修改为与真机一致的版本。
