发布智能体为 API 服务
将智能体发布为 API 服务后，可以通过调用 OpenAPI 的方式使用智能体程序。本文介绍如何将完成开发的智能体发布为 API 服务。
前提条件
要将智能体发布为 API，必须满足以下条件：
在发布前已创建个人令牌。详细说明可参考\n鉴权方式。
发布智能体为 API
以下是将智能体发布为 API 的详细步骤：
1.
登录扣子平台。
2.
在左侧导航栏中选择工作空间，并在页面顶部空间列表中选择个人空间或团队空间。
3.
在项目开发页面，选择目标项目，进入智能体的编排页面。
4.
在页面右上角，单击发布，进入智能体发布页面。
5.
在发布页面填写发布记录。
6.
在选择发布平台 > API 选项，选择 API。
7.
单击发布。
8.
发布成功后，单击完成。要查看发布历史，可以在智能体编排页面右上角，单击发布历史。
