生成营销 Banner 图
作者：疯狐
生成营销 Banner 图是一款用于制作营销图片的智能体，它可以根据指定的营销活动内容，快速生成活动 Banner 图片，降低活动运营成本、提高制图效率。
智能体效果
单击体验智能体：生成营销Banner图
在对话中输入活动的详细信息，例如活动商品名称及型号、活动类型、活动信息，智能体会根据要求制作出对应活动类型的营销活动 Banner 页面。

应用场景
制作商品营销活动 H5 页面时，相对于使用 H5 技术在原始图片上叠加图文混排、边框、蒙版、背景、文字装饰效果，直接在 H5 页面中呈现预先制作的静态 Banner 图片效果更好、加载速度更快。静态 Banner 图片中包含活动商品和活动内容等多种信息，不同的营销活动需要的文案和活动信息不同，所以每次制作图片时手动排版效率很低，制作周期长。
通过扣子图像流可以解决这个问题。你可以借助生成营销 Banner 图智能体，快速生成营销活动所需的 Banner 图。该智能体适用于各种活动商品的 H5 页面 Banner 图制作，复制图像流之后，你也可以根据需求生成其他商品的营销活动图片。
智能体设计
智能体的编排模式为工作流模式，不需要多轮对话功能，每次对话处理一个任务。工作流可以绑定一个卡片，用于提升展示效果。
智能体主要功能通过图像流和工作流实现，其中：
图像流：用于制作各种营销活动的主视觉图片和 Banner 图片模板。每个营销活动对应一个图像流，其中一个图像流用于生成主视觉图片，其他图像流生成对应营销活动的 Banner 模板，模板中也包含主视觉图片。另外，部分活动类型可以随机选择两种 banner 图模版中的一个，所以共计有八个生成banner图的图像流。
工作流：用于收集营销活动信息、活动商品信息，并将活动文案和商品信息填充到图片模板中，生成最终的 Banner 图片。其中活动商品信息由用户指定，比如礼包名称、券数量、活动话术等，智能体根据用户指定的商品名称在知识库中查询商品相关信息，并根据营销活动名称在表格知识库中查询活动文案。此工作流还支持通过随机变量选择背景色、模板风格。

功能实现
图像流：生成主视觉图
主视觉是品牌或活动在视觉传达上的核心图像。在活动方案中，通常主视觉图是固定的，每个营销活动 Banner 图片围绕主视觉图进行不同模式的编排，所以需要共用一个主视觉元素。通常情况下，活动商品的主视觉元素必须使用指定的活动商品素材图片，存在多款活动商品时，主视觉元素中也应包含多款商品，且支持设置多种布局模式。
在这种场景下，我们可以通过图像流将活动商品的素材图片加工为主视觉元素，处理方式为抠图、元素布局、替换背景。图像流中存在 3 个分支，分别用于加工活动商品素材、生成活动需要的背景图、生成活动元素图，最后再根据入参中设置的布局类型进行不同模式的布局设计，将多个商品素材拼接在一起，并更换背景图之后形成最终的主视觉元素。这个主视觉元素图片可以在其他生成 Banner 图的图像流中直接使用，叠加其他必选的图文混排元素。

\n
async def main(args: Args):\n
    params = args.params\n
\n
    mobile1url = ""\n
    mobile2url = ""\n
    mobile3url = ""\n
    postertype = ""\n
    idx = 0\n
\n
    partsm = params.get('input')\n
\n
    if partsm:\n
        for idx, element in enumerate(partsm, start=1):\n
            parts2 = element['output']\n
\n
            if idx == 1:\n
                mobile1url = parts2\n
            elif idx == 2:\n
                mobile2url = parts2\n
            elif idx == 3:\n
                mobile3url = parts2\n
            else:\n
                break\n
\n
    # 根据 idx 值选择 postertype\n
    if idx == 1:\n
        postertype = '1a'\n
    elif idx == 2:\n
