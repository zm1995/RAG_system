### 四、阶段 3：Web 界面开发（下轮优先）

#### 目标

开发一个本地 Web 聊天界面，替代命令行交互。

#### 技术选型

|方案|优点|适合场景|
|--|--|----|
|**Streamlit**|简单、代码少、快速原型|⭐ 优先推荐|
|Gradio|功能丰富、支持多模态|可选|
|FastAPI + Vue|灵活、专业|长期维护|

#### 功能需求

* [ ] 聊天对话框（输入问题 → 显示回答）
* [ ] 显示回答引用的来源笔记（文件名 + 路径）
* [ ] 对话历史记录（本次会话内）
* [ ] 可选：设置面板（调整 k 值、切换模型）
* [ ] 可选：显示检索到的相关文本块

#### 预期产出

* `app.py`：Streamlit 应用主文件
* 启动命令：`streamlit run app.py`
* 浏览器访问：`http://localhost:8501`
