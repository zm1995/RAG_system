# 步骤 2：知识库文件夹结构设计

## 推荐目录树

MyKnowledge/
├── 00_Inbox/       # 零时想法、未处理内容
├── 10_DailyNotes/  # 日志、工作记录、学习打卡
├── 20_Topics/      # 按主题组织的长期知识
├── 30_Projects/    # 有明确目标的项目
├── 40_Resources/   # 书籍、文献、模板、素材
├── 50_Permanent/   # 原子化、待 RAG 复用的核心笔记
└── 90_Templates/   # 可复用的笔记模板

## 使用原则

* 快速捕捉 → 00_Inbox
* 长期知识 → 20_Topics 或 40_Resources
* 任务驱动 → 30_Projects
* 终极形态 → 提炼到 50_Permanent

## Obsidian 实现

* 新建文件夹：右键 → 新建文件夹
* 快速创建带路径的笔记：`Ctrl+Shift+E`，输入 `00_Inbox/笔记名.md`
