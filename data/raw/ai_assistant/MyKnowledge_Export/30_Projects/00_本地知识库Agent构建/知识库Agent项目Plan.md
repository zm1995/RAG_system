## 一、核心结论（你已确认的）

1. **RAG 本质** = 检索 + 生成，先翻书（找资料），再答题。
1. **开发 RAG 需要的是大模型 API Key**，不是 Cursor Pro 的订阅凭证。
1. **Cursor Pro 不提供 API Key**，它只是编辑器工具，提供编程辅助。
1. **开发 RAG 时**：写代码用 Cursor Pro，运行代码需单独购买 API Key。
1. **推荐购买**：**DeepSeek API**（¥3/百万输入，性价比最高，学习够用）。
1. **替代方案**：阿里云百炼 Qwen3.7-Max（能力强，¥12/百万输入），智谱 GLM-5.1（长上下文）。
1. **零成本学习**：本地 Embedding 模型 + 本地 LLM（Ollama）完全免费。

## 三、分阶段学习计划（从零到 Agent）

### 阶段 0：前置准备（1 天）

* [ ] 安装 Python（3.10+）
* [ ] 安装 Obsidian
* [ ] 注册 DeepSeek 账号，获取 API Key（备用）

---

### 阶段 1：Obsidian 知识库构建（3~5 天）

**学习目标**：用 Obsidian 管理你的笔记/文档，为 RAG 准备高质量数据源。

|步骤|任务|输出|
|--|--|--|
|1.1|Obsidian 基础操作：创建笔记、Markdown 语法、链接 `[[]]`|一篇“我的 Obsidian 笔记”|
|1.2|文件夹分类 + 标签系统（#主题/子主题）|分类清晰的目录结构|
|1.3|定期整理 + 别名（aliases）增强检索|便于向量化的干净文档|
|1.4|导出 Obsidian 库为 Markdown 纯文本（供 RAG 读取）|`/obsidian_export/` 文件夹|

 > 
 > 📌 **本阶段自动生成 Markdown 总结**：`阶段1_Obsidian知识库构建总结.md`

---

### 阶段 2：本地向量化 + 本地存储（3~5 天）

**学习目标**：将 Obsidian 导出的 Markdown 文档切片、向量化、存入本地向量数据库。

|步骤|任务|技术选型|
|--|--|----|
|2.1|读取文件夹内所有 `.md` 文件|Python `pathlib`|
|2.2|文本分块（Chunking）|`langchain.text_splitter`（每块 500 字，重叠 100）|
|2.3|本地向量化（无需 API Key）|`BAAI/bge-small-zh-v1.5`（HuggingFace）|
|2.4|存入本地向量数据库|**ChromaDB**（轻量级）或 FAISS|
|2.5|测试检索：输入问题，返回最相关 3 个片段|验证向量库可用性|

 > 
 > 📌 **本阶段自动生成 Markdown 总结**：`阶段2_本地向量数据库构建总结.md`

---

### 阶段 3：本地 RAG 问答（3~5 天）

**学习目标**：检索 + 大模型生成答案，跑通完整 RAG 链路。

|步骤|任务|说明|
|--|--|--|
|3.1|从向量库检索相关片段（Top-K=3）|复用阶段 2 的检索代码|
|3.2|组装提示词（系统指令 + 资料 + 问题）|使用 DeepSeek/本地模型|
|3.3|调用 LLM 生成答案|先试 API（DeepSeek），再试本地（Ollama）|
|3.4|输出答案 + 引用来源（笔记文件名）|增强可信度|
|3.5|测试 10 个以上问题，评估回答质量|调整 chunk 大小 / top-k 值|

 > 
 > 📌 **本阶段自动生成 Markdown 总结**：`阶段3_本地RAG问答系统总结.md`

---

### 阶段 4：Agent 化（让 AI 自主决策）（5~7 天）

**学习目标**：Agent 不只“检索一次”，而是能多轮思考、调用工具。

|步骤|任务|工具/框架|
|--|--|-----|
|4.1|理解 Agent 原理：ReAct 模式（思考 → 行动 → 观察）|阅读 LangChain Agent 文档|
|4.2|给 Agent 加第一个工具：向量检索工具（SearchMyNotes）|封装阶段 3 的检索函数|
|4.3|给 Agent 加第二个工具：网络搜索（可选，百度/Google）|SerpAPI 或 Tavily|
|4.4|让 Agent 自主决定：先搜笔记，不够再联网|使用 LangGraph 或 LlamaIndex Agent|
|4.5|测试复杂问题：“我上周笔记里提到的那个技术方案，网上有什么最新进展？”|验证 Agent 的多步推理|
