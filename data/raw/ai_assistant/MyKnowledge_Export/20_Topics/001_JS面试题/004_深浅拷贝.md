## ✅ 一句话粗暴定义

* **浅拷贝（Shallow Copy）**：**只复制"第一层"**，如果属性是引用类型（对象/数组），拷贝的是**地址**，新旧对象**共享**这个引用。
* **深拷贝（Deep Copy）**：**递归复制"所有层"**，引用类型属性也会被完整克隆，新旧对象**完全独立**，互不影响。

 > 
 > **记住：浅=只刮一层皮，深=连根拔起。**

## 🧪 用代码直观对比（跑一遍就懂）

````javascript
// 原始对象：有基本类型 + 引用类型
const original = {
  name: 'Tom',        // 基本类型
  age: 25,            // 基本类型
  address: {          // 引用类型（嵌套对象）
    city: 'Beijing',
    zip: 100000
  },
  hobbies: ['coding', 'reading']  // 引用类型（数组）
};

// ========== 浅拷贝 ==========
const shallow = { ...original };
shallow.name = 'Jerry';           // 修改基本类型 → 不影响原对象
shallow.address.city = 'Shanghai'; // 修改嵌套对象 → 影响原对象！
shallow.hobbies.push('swimming');  // 修改数组 → 影响原对象！

console.log(original.name);        // 'Tom'（没变）
console.log(original.address.city); // 'Shanghai'（变了！）
console.log(original.hobbies);     // ['coding', 'reading', 'swimming']（变了！）

// ========== 深拷贝 ==========
const deep = JSON.parse(JSON.stringify(original));
deep.address.city = 'Chengdu';     // 修改嵌套对象
deep.hobbies.push('gaming');       // 修改数组
console.log(original.address.city); // 'Shanghai'（没变！）
console.log(original.hobbies);     // ['coding', 'reading', 'swimming']（没变！）
````

## 📋 浅拷贝的3种实现方式

|方法|适用场景|示例|
|--|----|--|
|**展开运算符**|对象/数组|`{ ...obj }` / `[...arr]`|
|**Object.assign()**|对象|`Object.assign({}, obj)`|
|**数组方法**|数组|`arr.slice()` / `arr.concat()`|

**注意**：`Object.assign` 和展开运算符只复制**可枚举的自身属性**，不会复制原型链上的属性。

## 📋 深拷贝的3种实现方式

|方法|优点|缺陷（面试必问）|
|--|--|--------|
|**JSON.parse(JSON.stringify(obj))**|简单、快速|❌ 无法拷贝 `Date` → 变成字符串<br>❌ 无法拷贝 `RegExp` → 变成空对象 `{}`<br>❌ 无法拷贝 `Function` → 丢失<br>❌ 无法拷贝 `undefined` / `Symbol` → 丢失<br>❌ 无法处理**循环引用** → 报错|
|**structuredClone()**（Node 17+ / 浏览器）|原生API、支持循环引用、支持Date/RegExp|❌ 无法拷贝 `Function`<br>❌ 无法拷贝 `Symbol`|
|**递归手写实现**|完全可控、支持所有类型|⚠️ 需要自己处理边界（循环引用、特殊类型）|

### 各方法示例：

````javascript
const obj = {
  num: 1,
  str: 'hello',
  bool: true,
  date: new Date(),
  reg: /test/g,
  func: function() { console.log('hi'); },
  undef: undefined,
  sym: Symbol('id'),
  self: null  // 先设为null，后面改成循环引用
};
obj.self = obj;  // 循环引用

// 方法1：JSON（会报错！）
JSON.parse(JSON.stringify(obj));  // TypeError: Converting circular structure to JSON

// 方法2：structuredClone（Node 17+）
const cloned = structuredClone(obj);
console.log(cloned.date instanceof Date);  // true
console.log(cloned.reg instanceof RegExp); // true
console.log(cloned.self === cloned);       // true（循环引用正确处理）
// 但 cloned.func 丢失，cloned.undef 丢失，cloned.sym 丢失

// 方法3：手写递归（最完善）
function deepClone(value, hash = new WeakMap()) {
  // 基本类型 或 null
  if (value === null || typeof value !== 'object') return value;
  
  // 循环引用处理
  if (hash.has(value)) return hash.get(value);
  
  // Date
  if (value instanceof Date) return new Date(value);
  // RegExp
  if (value instanceof RegExp) return new RegExp(value.source, value.flags);
  // Map / Set（如果需要）
  if (value instanceof Map) return new Map([...value]);
  if (value instanceof Set) return new Set([...value]);
  
  // 数组 / 对象
  const result = Array.isArray(value) ? [] : {};
  hash.set(value, result);
  
  for (const key in value) {
    if (value.hasOwnProperty(key)) {
      result[key] = deepClone(value[key], hash);
    }
  }
  return result;
}

const cloned2 = deepClone(obj);
console.log(cloned2.func === obj.func);  // true（函数直接引用，因为函数无法克隆）
console.log(cloned2.self === cloned2);   // true
````

## 🎯 面试致命追问（附标准答案）

**问：** "浅拷贝和深拷贝有什么区别？"  
**答：** "浅拷贝只复制对象的'第一层'属性，如果属性是基本类型则拷贝值，如果是引用类型则拷贝地址，新旧对象共享该引用。深拷贝则递归复制所有层，新旧对象完全独立。"

**问：** "`Object.assign()` 是深拷贝还是浅拷贝？"  
**答：** "**浅拷贝**。它只复制第一层属性，嵌套对象仍然是共享的。"

**问：** "`JSON.parse(JSON.stringify(obj))` 有什么缺陷？"  
**答：** "无法处理 `Date`、`RegExp`、`Function`、`undefined`、`Symbol`，且遇到循环引用会报错。适用于纯数据对象（JSON安全）。"

**问：** "如何实现一个完善的深拷贝？"  
**答：** "递归遍历 + `WeakMap` 处理循环引用 + 特殊类型（`Date`/`RegExp`/`Map`/`Set`）判断。函数通常直接引用，因为无法深拷贝。"

**问：** "`structuredClone` 和手写深拷贝哪个好？"  
**答：** "`structuredClone` 是原生API，性能好且支持循环引用，但无法拷贝函数和 `Symbol`。手写方案更灵活，可以根据业务需求定制。"
