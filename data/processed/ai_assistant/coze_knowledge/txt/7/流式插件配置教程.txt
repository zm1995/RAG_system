流式插件配置教程
扣子支持流式插件，智能体或工作流在单次调用插件时，可以输出多条消息，每条消息能够以类似打字机的效果逐条动态显示，实现流式输出效果。
流式插件概述
流式插件适用于需要实时处理和展示连续消息流的场景，它能够提供动态的消息输出，增强用户体验，例如聊天机器人和实时通知场景。
说明
绑定了流式插件的智能体和应用不支持以卡片的形式输出消息，即便是流式插件绑定了卡片，也不会产生任何效果。\n
在智能体中使用流式插件，流式输出的内容不会经过大模型处理，对于非流式输出的最后一条消息内容，可以选择是否需要大模型处理，而在工作流中使用流式插件，流式输出的内容都不会经过大模型节点处理。\n
仅基于已有服务创建插件时，支持配置流式插件，而在 IDE 中创建插件和创建端插件都不支持配置流式插件。

协议实现
配置流式插件，你的业务接口需要实现 Server-Sent Events (SSE) 传输协议，并遵守扣子插件所定义的数据协议规范。

配置流式插件
你已经创建了一个插件，API 接口已经实现 Server-Sent Events (SSE) 传输协议，并且 API 接口遵守扣子插件所定义的数据协议规范，详情请参考\n基于 API 创建一个插件。
1.
登录扣子平台。
2.
在左侧导航栏中，选择工作空间，并在页面顶部空间列表中选择个人空间或团队空间。
系统默认创建了一个个人空间，该空间内创建的资源例如智能体、插件、知识库是你的私有资源，其他用户不可见。你也可以创建团队或加入其他团队，团队内的资源可以和其他团队成员共享。更多信息，请参考\n管理团队。
3.
在资源库页面，单击目标插件。
4.
在插件详情页，单击使用代码编辑工具的图标。
5.
在更新插件页面，单击编辑。
6.
在 openapi (填写 yaml) 区域，找到需要配置为流式输出的接口，在operationId下添加x-runMode: Streaming。
代码示例如下：
info:\n
    description: stream output demo\n
    title: Stream Demo\n
    version: v1\n
openapi: 3.0.1\n
paths:\n
    /your/stream/api:\n
        post:\n
            operationId: stream\n
            x-runMode: Streaming\n
            requestBody:\n
                content:\n
                    application/json:\n
                        schema:\n
                            type: object\n
            responses:\n
                "200":\n
                    content:\n
                        application/json:\n
                            schema:\n
                                type: object\n
                    description: empty response\n
                default:\n
                    description: ""\n
            summary: stream demo\n
servers:\n
    - url: https://www.demo.com

使用流式插件
你可以在智能体或工作流中使用流式插件，详情可参考\n使用插件。
注意
在工作流中使用流式插件，请注意：\n
即时数据输出：当执行到流式插件节点时，系统会直接输出流式插件返回的数据。只有当所有数据输出完毕后，工作流才会继续执行后续节点。\n
不支持获取返回值：工作流中的节点暂不支持从流式插件节点获取返回值。\n
调试限制：在工作流调试过程中，由于流式插件的特性，无法直接展示其输出效果。因此，为了查看流式插件的实际输出，建议在智能体中绑定使用了流式插件的工作流，以便观察和验证流式输出的实际效果。
在工作流中使用流式插件，请注意：
即时数据输出：当执行到流式插件节点时，系统会直接输出流式插件返回的数据。只有当所有数据输出完毕后，工作流才会继续执行后续节点。
不支持获取返回值：工作流中的节点暂不支持从流式插件节点获取返回值。
调试限制：在工作流调试过程中，由于流式插件的特性，无法直接展示其输出效果。因此，为了查看流式插件的实际输出，建议在智能体中绑定使用了流式插件的工作流，以便观察和验证流式输出的实际效果。
