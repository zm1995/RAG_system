管理专业版用户
扣子专业版支持企业级 AI 应用的搭建及团队管理。扣子专业版支持创建专业版子用户，并将其添加到同一个团队空间，共享数据库、插件等资源。在企业级应用开发场景下，公司管理员可以为员工分别创建子用户，将他们按部门划分到不同的扣子空间中，便于部门内的协同开发和资源共享，所有子用户产生的费用均由主账号统一支付。\n
火山子用户介绍\n
火山子用户是扣子专业版中的一种虚拟的身份类型，由扣子专业版账号在火山引擎控制台中创建和管理。\n
扣子专业版中，用户相关的概念如下：\n
\n
概念\n
	
说明\n


主账号\n
	
扣子专业版账号又称为主账号。主账号可以创建子用户、管理用户及权限、设置团队别名、子用户登录地址。\n


子用户\n
	
由主账号在火山引擎用户管理页面中创建的用户，隶属于主账号，和主账号一样拥有扣子平台（coze.cn）的全部操作权限，默认不具备其他权限。\n


IAM 用户\n
	
火山引擎中的身份类型，子用户开启允许访问火山引擎后，扣子专业版会为此用户创建并关联一个同名的 IAM 用户，并为其授予扣子专业版的只读权限 CozeReadOnlyAccess。子用户如果需要其他产品的权限，可以由主账号为其对应的 IAM 用户授权。\n

\n
空间限制\n
	
影响说明\n


禁止内部用户创建空间\n
	
除主账号以外，其他内部用户无法创建团队空间。\n
仅主账号可创建团队空间，便于主账号管理所有收费资源，管控团队的资源消耗。\n


禁止空间添加外部用户\n
	
除主账号以外，其他内部用户创建的所有空间均禁止任何外部用户加入。\n
此操作可以限制仅内部用户才能使用专业版的收费资源，避免外部黑灰产账号滥用资源，保障了团队空间的信息安全和数据安全。\n


禁止加入外部空间\n
	
包括主账号和子用户在内的所有内部用户，均禁止加入外部空间。\n
此操作有利于主账号统一管控团队内的业务产出，内部用户搭建的智能体和应用等资源完全隶属于团队内部，只在团队内部共享。\n

常见问题\n
火山子用户和扣子团队空间成员之间是什么关系？\n
火山子用户由对应的主账号统一管理。例如公司管理员可以为不同职能的员工分别创建子用户，将他们按部门划分到不同的扣子团队空间中，便于部门内的协同开发和资源共享，所有子用户产生的费用都由主账号统一支付。\n
扣子团队空间成员是团队中的一个角色，如果成员是基础版用户，那么其不受任何主账号管理。\n
火山子用户和 IAM 用户之间是什么关系？\n
在扣子专业版控制台用户管理页面创建的火山子用户是一个虚拟身份，拥有独立的扣子平台（coze.cn）账号。火山子用户被授予火山方舟的权限后，会被绑定一个新的、同名的 IAM 用户，用于承载和管理火山引擎产品相关的权限，例如 IAM 用户被授予 CozeFullAccess 权限之后，火山子用户可以在火山引擎扣子专业版控制台中进行所有管理操作，包括购买资源包、创建新的火山子用户等。\n
火山子用户可以访问扣子平台吗？\n
在火山引擎新建的火山子用户默认拥有扣子平台（coze.cn）的所有权限，包括创建空间、加入空间、管理智能体等。\n
火山子用户可以查看用量、购买资源包吗？\n
火山子用户默认不具备火山引擎扣子专业版控制台的任何权限，例如无法访问控制台、查看用量等。\n
主账号可以在 IAM 控制台为子用户添加扣子专业版的系统权限，例如被授予 CozeFullAccess 权限之后， 火山子用户可以在火山引擎扣子专业版控制台中进行所有管理操作，包括购买资源包、创建新的火山子用户等。\n
火山子用户可以添加方舟模型吗？\n
火山子用户默认不具备火山方舟产品的任何权限，若有需要，你可以通过火山引擎主账号在用户管理页面编辑用户，为火山子用户添加火山方舟的授权，添加权限后，火山子用户可以登录火山引擎方舟控制台，添加方舟模型推理接入点，或删除推理接入点。\n
详情请参考\n为专业版用户授权。\n
火山子用户产生的费用怎么支付？\n
子用户归属于主账号，其产生的所有费用均计入子用户对应主账号的账单，并由主账号统一支付。\n
主账号下已经有 IAM 用户，如何添加扣子平台（coze.cn）的权限？\n
主账号下已经有 IAM 用户，你可以为 IAM 用户授权访问扣子平台，详情请参考\n为专业版用户授权。 \n
添加团队空间成员时，找不到子用户\n
添加专业版子用户成员时，需要使用该子用户在扣子平台（coze.cn）中的用户名，而不是其在火山引擎控制台用户管理页面上的子用户名。\n
子用户可以在扣子平台左下角查看当前登录账号的用户名。\n

错误信息\n
	
说明\n


无权限访问\n
	
原因：主账号未授予该子用户访问火山引擎控制台的权限。\n
解决方案：通过火山引擎主账号在用户管理页面编辑用户，为火山子用户添加火山方舟的授权。\n


用户名或密码不匹配\n
	
原因：子用户登录时输入的用户名和密码错误。\n
解决方案：输入正确的用户名和密码。如果忘记密码，可以请主账号为子用户重置密码。\n


团队别名不存在\n
	
原因：子用户登录时，团队别名输入错误。\n
解决方案：输入正确的团队别名。如果忘记团队别名，可以联系主账号获取。\n


The parameter %v Include sensitive Word\n
	
原因：创建用户、修改团队别名或登录地址时，输入的字符串中包含敏感词。\n
解决方案：建议重新输入，避免涉及敏感词。\n


same name instance exist\n
	
原因：修改团队登录地址时，新地址与系统中已存在的地址重复。\n
解决方案：建议重新设置团队登录地址。\n


same name company alis instance exist\n
	
原因：自定义团队别名时，新别名与系统中已存在的别名重复。\n
解决方案：建议重新设置团队别名。\n


no app permissions\n
	
原因：扣子子用户权限异常，导致子用户登录扣子平台时报错。\n
解决方案：主账号在用户管理页面编辑用户，根据页面提示重新授权。\n


SLRNotExist "SLR角色不存在"\n
	
原因：扣子产品的服务关联角色 ServiceRoleForCoze 被删除，导致子用户部分控制台操作报错。\n
解决方案：稍后再试。也可以通过主账号在 IAM 控制台中创建角色，并指定信任实体为服务，并选择 Coze 服务。\n

常见问题
火山子用户和扣子团队空间成员之间是什么关系？
火山子用户由对应的主账号统一管理。例如公司管理员可以为不同职能的员工分别创建子用户，将他们按部门划分到不同的扣子团队空间中，便于部门内的协同开发和资源共享，所有子用户产生的费用都由主账号统一支付。
扣子团队空间成员是团队中的一个角色，如果成员是基础版用户，那么其不受任何主账号管理。
火山子用户和 IAM 用户之间是什么关系？
在扣子专业版控制台用户管理页面创建的火山子用户是一个虚拟身份，拥有独立的扣子平台（coze.cn）账号。火山子用户被授予火山方舟的权限后，会被绑定一个新的、同名的 IAM 用户，用于承载和管理火山引擎产品相关的权限，例如 IAM 用户被授予 CozeFullAccess 权限之后，火山子用户可以在火山引擎扣子专业版控制台中进行所有管理操作，包括购买资源包、创建新的火山子用户等。
火山子用户可以访问扣子平台吗？
在火山引擎新建的火山子用户默认拥有扣子平台（coze.cn）的所有权限，包括创建空间、加入空间、管理智能体等。
火山子用户可以查看用量、购买资源包吗？
火山子用户默认不具备火山引擎扣子专业版控制台的任何权限，例如无法访问控制台、查看用量等。
主账号可以在 IAM 控制台为子用户添加扣子专业版的系统权限，例如被授予 CozeFullAccess 权限之后， 火山子用户可以在火山引擎扣子专业版控制台中进行所有管理操作，包括购买资源包、创建新的火山子用户等。
火山子用户可以添加方舟模型吗？
火山子用户默认不具备火山方舟产品的任何权限，若有需要，你可以通过火山引擎主账号在用户管理页面编辑用户，为火山子用户添加火山方舟的授权，添加权限后，火山子用户可以登录火山引擎方舟控制台，添加方舟模型推理接入点，或删除推理接入点。
详情请参考\n为专业版用户授权。
火山子用户产生的费用怎么支付？
子用户归属于主账号，其产生的所有费用均计入子用户对应主账号的账单，并由主账号统一支付。
主账号下已经有 IAM 用户，如何添加扣子平台（coze.cn）的权限？
主账号下已经有 IAM 用户，你可以为 IAM 用户授权访问扣子平台，详情请参考\n为专业版用户授权。
添加团队空间成员时，找不到子用户
添加专业版子用户成员时，需要使用该子用户在扣子平台（coze.cn）中的用户名，而不是其在火山引擎控制台用户管理页面上的子用户名。
子用户可以在扣子平台左下角查看当前登录账号的用户名。
错误信息参考
火山子用户登录账号的过程中，页面可能会弹窗显示错误信息，例如无权限访问等。常见的报错信息如下，您可以根据以下解决方案尝试处理。如果无法解决，可通过工单系统联系售后处理。
错误信息\n
	
说明\n


无权限访问\n
	
原因：主账号未授予该子用户访问火山引擎控制台的权限。\n
解决方案：通过火山引擎主账号在用户管理页面编辑用户，为火山子用户添加火山方舟的授权。\n


用户名或密码不匹配\n
	
原因：子用户登录时输入的用户名和密码错误。\n
解决方案：输入正确的用户名和密码。如果忘记密码，可以请主账号为子用户重置密码。\n


团队别名不存在\n
	
原因：子用户登录时，团队别名输入错误。\n
解决方案：输入正确的团队别名。如果忘记团队别名，可以联系主账号获取。\n


The parameter %v Include sensitive Word\n
	
原因：创建用户、修改团队别名或登录地址时，输入的字符串中包含敏感词。\n
解决方案：建议重新输入，避免涉及敏感词。\n


same name instance exist\n
	
原因：修改团队登录地址时，新地址与系统中已存在的地址重复。\n
解决方案：建议重新设置团队登录地址。\n


same name company alis instance exist\n
	
原因：自定义团队别名时，新别名与系统中已存在的别名重复。\n
解决方案：建议重新设置团队别名。\n


no app permissions\n
	
原因：扣子子用户权限异常，导致子用户登录扣子平台时报错。\n
解决方案：主账号在用户管理页面编辑用户，根据页面提示重新授权。\n


SLRNotExist "SLR角色不存在"\n
	
原因：扣子产品的服务关联角色 ServiceRoleForCoze 被删除，导致子用户部分控制台操作报错。\n
解决方案：稍后再试。也可以通过主账号在 IAM 控制台中创建角色，并指定信任实体为服务，并选择 Coze 服务。
